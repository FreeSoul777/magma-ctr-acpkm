# Magma CTR-ACPKM

О проекте
Данная программа реализует блочный шифр «Магма» (ГОСТ Р 34.12-2015) в режиме CTR-ACPKM (ГОСТ Р 34.13-2015) с размером секции N = 128 бит.

Проект выполнен в рамках лабораторной работы по курсу «Криптографические протоколы» и предназначен исключительно для учебных целей.

## Основные характеристики:
- Длина блока: 64 бита
- Длина ключа: 256 бит
- Количество раундов: 32
- Сеть Фейстеля с фиксированными S-блоками (RFC 8891)

## Реализованные механизмы защиты (КС3):
- Защита ключей в памяти (mlock)
- Безопасная очистка памяти (secure_zero)
- Контроль целостности исполняемого файла (CRC32)
- Контроль работоспособности (self-test по RFC 8891)
- Контроль времени жизни ключа
- Логирование событий в magma.log
- Проверка прав доступа к ключевому файлу (0600)

## Требования
- Операционная система: Linux (Ubuntu 20.04+, Debian 11+)
- Компилятор: GCC 9+ (поддержка C99)
- Система сборки: CMake 3.10+

## Сборка

### Клонирование репозитория:
```text
git clone https://github.com/FreeSoul777/magma-ctr-acpkm
cd magma-ctr-acpkm
```

### Сборка проекта:
```text
mkdir build && cd build
cmake ..
make
```

### Сборка с тестами:
```text
cmake .. -DBUILD_TESTS=ON -DDEV_MODE=ON
make
```

### Использование
1. Подготовка ключевого файла (32 байта):
```text
dd if=/dev/urandom of=key.bin bs=32 count=1
chmod 600 key.bin
```

2. Шифрование файла:
```text
./magma --key-file key.bin enc input.txt output.enc
```

3. Дешифрование файла:
```text
./magma --key-file key.bin dec output.enc decrypted.txt
```

## Флаги CMake
|   Флаг   |  Значение  |
|----------|------------|
| -DBUILD_TESTS=ON | Сборка тестового модуля magma_tests         |
| -DDEV_MODE=ON    | Режим разработки (отключает проверку CRC32) |

## Тестирование
Запуск криптографических тестов и бенчмарков:
```text
./magma_tests
```
